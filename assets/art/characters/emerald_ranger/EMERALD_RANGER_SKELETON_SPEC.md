# 翡翠游侠 Skeleton2D 骨骼候选规范 v0.1

此版本用于替代僵硬的部件节点旋转表现，但当前仍是候选，不覆盖原切片预览。

## 骨骼层级

- 根骨：`Pelvis`。
- 身体链：`Pelvis → Spine → Head → Hat → Feather`。
- 持弓臂：`Spine → FrontUpperArm → FrontForearm → BowGrip`。
- 拉弦臂：`Spine → RearUpperArm → RearForearm`。
- 双腿：`Pelvis → Thigh → Shin`。
- 箭袋、腰包、羽毛为附属骨，可在主姿势之后叠加轻微延迟摆动。

机器可读层级见 `emerald_ranger_skeleton_v01.json`。

## 绑定策略

- 头、躯干、帽子、弓、箭袋和腰包保持刚性绑定，避免缩小后轮廓变形。
- 上下臂、大腿和小腿沿骨轴重叠约 18–28 像素，以隐藏肩、肘和膝处的透明裂缝。
- 当前候选使用双骨解析IK约束手脚。正式编辑器版本可换成 `SkeletonModification2DTwoBoneIK`，结果目标应保持一致。
- 弓绑定到 `BowGrip` 末端骨；弓弦仍由三点线动态绘制；搭载箭绑定拉弦目标，在释放事件后隐藏。
- 脚部目标应来自视觉地表采样结果，但不得反向修改角色物理坐标或碰撞体。

## 动画表现

- 瞄准阶段驱动持弓手目标从下垂位移到射线方向。
- 蓄力阶段只移动拉弦手目标，IK自动求解肩肘角度。
- 释放阶段箭先离开搭载骨，随后交给现有飞行箭实体。
- 后坐只作用于脊柱、头、帽羽和附属骨；双脚目标保持锁定，避免角色整体漂浮。
- 继续使用12 FPS关键姿势采样与插值，保留幽默夸张但避免关节反折。

## 接入建议

- 将正式骨骼角色作为现有 `Archer` 的视觉子场景；不要把候选预览脚本合并进核心玩法脚本。
- 正式接入时，将现有蓄力比例映射到骨骼动画时间或IK目标位置。
- 命中区仍沿用现有头、躯干、腿三段碰撞，不从骨骼蒙皮轮廓生成碰撞。
- 船骸鲨客使用同样的骨骼命名规范，以便共用动画状态接口，但骨长、动作滞后和二级摆动幅度单独设置。
