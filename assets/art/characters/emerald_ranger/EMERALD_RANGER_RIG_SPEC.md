# 翡翠游侠切片骨架与射击动画规范 v0.2

本规范只描述美术骨架、动画节奏和视觉事件，不改变弹道、伤害、碰撞或回合逻辑。

## 骨架方案

- 默认严格侧视朝右，根节点为骨盆；脚底接触当前地形采样点。
- 16 个独立透明部件：头、帽、羽毛、躯干、前后大小臂、前后大腿与小腿靴、弓、箭袋、搭载箭、腰包。
- 层级由后向前：箭袋 → 后腿 → 后臂 → 躯干 → 前腿 → 腰包 → 头 → 帽与羽毛 → 前臂 → 弓 → 弦 → 箭。
- 关节像素锚点和默认偏移见 `emerald_ranger_anchors_v02.json`。羽毛使用清理孤立碎片后的 `v03`，其余部件使用 `v02`。
- 高分辨率骨架预览缩放为 `0.38`；接入 100 像素高角色时，应以完整装配后的包围盒计算统一缩放，不分别缩放肢体。

## 首轮射击循环

作者采样率为 12 FPS，Godot 在关键姿势之间插值。完整预览循环 3.2 秒；正式战斗中应由玩法已有事件截取相应阶段，而不是强制改变回合时长。

| 阶段 | 预览时间 | 视觉意图 | 程序事件建议 |
| --- | ---: | --- | --- |
| 待机 | 0.00–0.45 秒 | 小幅呼吸、帽羽轻摆 | 无 |
| 举弓 | 0.45–0.82 秒 | 前臂抬起，弓进入射线方向 | 瞄准开始 |
| 蓄力 | 0.82–1.62 秒 | 拉弦手靠近面部，身体微后仰 | 映射当前蓄力比例 |
| 释放 | 1.62–1.74 秒 | 弦复位，搭载箭前移并隐藏 | 在现有放箭事件同帧触发 |
| 后坐 | 1.68–2.18 秒 | 躯干、帽羽和持弓臂产生夸张反向摆动 | 纯视觉，不加位移或冲量 |
| 恢复 | 2.15–3.12 秒 | 肢体回到待机轮廓 | 回合状态允许时播放 |

## 接入约束

- 正式接入推荐将部件放入独立 `Node2D` 关节层级，或转换为 `Bone2D/Skeleton2D`；不要把预览脚本直接并入 `archer.gd`。
- 角色根节点继续跟随现有 `Archer.global_position`。动画只改变视觉子节点，不改变角色碰撞体或弹道出发点。
- 释放事件发生后必须隐藏 `nocked_arrow`；飞行箭仍由现有箭实体负责。弦是程序绘制线条，不需要烘焙贴图。
- 左向版本优先在角色视觉根节点使用水平镜像；程序需同时镜像关节偏移、弓弦点与箭的视觉方向，不镜像世界弹道计算。
- 受击插箭将来应挂到预定义插箭槽位，最多显示 12 支；新对局清空。轻度血迹使用独立帧特效，不写入这些常态部件。

## 后续动作顺序

1. 将本射击竖切接到候选角色场景并校准现有箭口位置。
2. 制作待机、移动、普通受击、爆头受击、失败倒地、胜利动作。
3. 为船骸鲨客按同一命名、帧率和事件规范拆件；保留更沉重、更滞后的动作个性，但不自行改变玩法数值。
